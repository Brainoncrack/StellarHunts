# Multiplayer Puzzle Set

This directory contains 10 head-to-head puzzles for the StellarHunts multiplayer queue.

## Match tiers

| Tier | Puzzles | Difficulty |
| --- | --- | --- |
| Beginner | 3 | Easy |
| Intermediate | 3 | Medium |
| Advanced | 2 | Hard |
| Expert | 2 | Master |

Puzzles in each tier use the same difficulty level and include 3-5 test cases. The set covers Stellar fundamentals, account reserves, consensus, Soroban authorization and storage, trustlines, cryptography, claimable balances, and transaction timing. A balanced match should select puzzles only from the players' shared `match_tier`.
